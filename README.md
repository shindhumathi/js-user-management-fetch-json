# User Management Using Fetch API and JSON

A user management application demonstrating communication between JavaScript frontend and PHP backend using Fetch API and JSON responses.

## Features

- Fetch user data from PHP backend
- Receive backend responses in JSON format
- Display user records dynamically
- Handle asynchronous requests
- Process JSON responses using JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- PHP
- MySQL
- JSON

## Concepts Practiced

- Fetch API
- Async/Await
- JSON encoding using PHP
- JSON parsing using JavaScript
- Backend and frontend communication
- HTTP requests and responses
- DOM manipulation
